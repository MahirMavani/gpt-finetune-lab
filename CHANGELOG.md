# Changelog

All notable changes to **Custom-Style GPT-2 Fine-Tuning Lab** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-28

### Added
- Interactive web studio for GPT-2 fine-tuning and synthetic dataset management.
- PyTorch + Hugging Face Transformers backend with loss tracking endpoints.
- Docker configuration for containerized deployment on Hugging Face Spaces.
- Netlify static deployment setup with dynamic API target switching.
- MIT open source license and technical documentation.

### Fixed
- Stabilized loss evaluation loop on custom synthetic CSV text inputs.
- Resolved Netlify deployment configurations.
